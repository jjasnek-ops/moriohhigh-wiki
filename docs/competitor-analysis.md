## 机会排序

1. Stand获取/失败原因：已有可读游戏UI，增加来源时间点、条件对照和当前版本限制。
2. PC controls及新手first steps：查询结果常混入tier list/宽泛入门页，精确HUD表和首轮步骤更能直接解决问题；现有资料仍是录像参考。
3. Code redemption/membership：字符串竞争强，操作问题可更具体；加入社区目前只做明确归属的二手说明。
4. Stand reroll cost/Arrow compatibility：沿用主指南的独立小节，避免创建同质页面。
5. 真实Stand数据库/任务路线：玩家意图存在竞品信号，但制作成本高、本站证据不足；留待当前客户端或开发者资料。

## 不值得当前投入

不制作无实测依据的tier list、不从JoJo原作补技能、不制造地图/NPC/任务页、不抢作弊script词、不扩大量语言页。社区Trello和Discord所有权没有一手确认；不把媒体互相转载当两个独立游戏验证。Reddit搜索没有取得可支持新增机制的实测讨论；已有推广码帖不作一手机制证据。官方游戏页可读、Place-to-Universe API200，games/group API访问受限；私人Discord公告未获可读取证据，不绕过登录。
