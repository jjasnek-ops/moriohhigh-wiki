## How do you redeem Morioh High codes?

The two checked publishers describe **Menu → Settings → Codes**, followed by entering the code and selecting **Redeem**. MrGuider gives **M** as the menu shortcut; the same-game HUD also labels M as Menu in the [PC controls reference](/guides/controls/). The Settings and Codes screens remain publisher-reported instructions rather than a flow tested by this wiki.

1. Open the verified [Morioh High game](https://www.roblox.com/games/111838814545019/Morioh-High).
2. Open **Menu** using the on-screen button or the reported **M** shortcut on PC.
3. Select **Settings**, then **Codes**, if your current menu shows those options.
4. Paste one code exactly as copied above.
5. Select **Redeem** and read the game’s response.

If your interface differs, follow its current instructions. For help opening the correct experience, use the [Roblox launch guide](/guides/how-to-play/). A build number and mobile-specific redemption controls were not available in the checked sources.

## Why might a code fail?

A failed attempt does not by itself tell you whether the code expired, was already used, or was entered incorrectly. First compare the pasted spelling with the list and check that you joined Morioh High by **Not A Stand Game**. Use the wording of the game’s actual response to understand your particular attempt; this page does not invent error-message meanings or eligibility requirements.

There is no independently verified expired-code table here yet. A publisher removing a string, or a source becoming unavailable, is not enough to label it expired. You can obtain a Stand through the [documented fight or Arrow methods](/guides/how-to-get-a-stand/) without relying on a claimed code reward.
